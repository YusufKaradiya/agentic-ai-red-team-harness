# Evaluation Dashboard

## Objective

The evaluation dashboard provides measurable security results
for the Agentic AI Red-Team Harness.

## Evaluation Corpus

The current synthetic corpus contains:

- Direct Prompt Injection cases
- Indirect Prompt Injection cases
- Tool Abuse cases
- Data Exfiltration cases
- Benign control cases

## Metrics

### Detection Rate

Percentage of malicious test cases correctly blocked.

Detection Rate =

True Positives / Total Malicious Cases × 100

### Attack Success Rate

Percentage of malicious test cases incorrectly allowed.

Attack Success Rate =

False Negatives / Total Malicious Cases × 100

### False Positive

A benign request incorrectly blocked.

### False Negative

A malicious request incorrectly allowed.

### Average Risk Score

Average risk score generated by the detection engine
across evaluated cases.

## Evaluation Categories

The dashboard reports performance by:

- Attack category
- Severity
- Decision
- Result type

## Error Analysis

False positives and false negatives are displayed separately
to support security error analysis.

## Limitations

The current evaluation uses a synthetic rule-based corpus.

The results may not generalize to real-world attacks.

The corpus should be expanded with:

- paraphrased attacks
- obfuscated attacks
- unseen attack patterns
- multi-step attack scenarios

## Baseline Comparison

A baseline agent will be evaluated using the same corpus
and metrics in a later experiment.

## Reproducibility

Evaluation results are generated programmatically from the
attack corpus and the current detector implementation.
